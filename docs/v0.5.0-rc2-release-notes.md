# ProjectAtlas v0.5.0-rc2 release notes

ProjectAtlas v0.5.0-rc2 repairs the six installed-product defects found by the RC1 audit while preserving v0.4.5 as the stable GitHub Latest release.

## Highlights

- Add bounded, trusted ProjectAtlas lifecycle guidance to the packaged plugin.
- Keep classified file discovery limited to real indexed files across CLI and MCP.
- Ship version-matched package guidance with ordinary `atlas` and `projectatlas` examples and the inherited-PATH restart boundary.
- Admit the official versioned optional-parser archive name while retaining target, manifest, digest, content, and containment checks.
- Preserve JSON, Unicode, empty-value, and metacharacter arguments through the native Windows `atlas` alias.
- Make Windows parser-pack containment admission idempotent and fail closed for inherited, denied, or overprivileged profile ACLs while retaining retry-safe cleanup.

## Verification

The candidate is published only after exact-head Rust, IssueOps, package, parser-pack, and installed-product proof passes on Windows, Linux, macOS x64, and macOS arm64. It is a non-draft GitHub prerelease; stable promotion remains separate work in #602, and v0.4.5 remains Latest.

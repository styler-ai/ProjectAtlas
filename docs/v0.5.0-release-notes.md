# ProjectAtlas 0.5.0

ProjectAtlas gives coding agents a persistent map of a repository: responsibility, source summaries, symbols, callers, dependencies, and exact current source. Version 0.5.0 brings the accepted RC4 line to stable.

## Highlights

- Built-in PHP 8 navigation and bounded PDF/DOCX text extraction, with source evidence, parser provenance, and incomplete-coverage reporting.
- The short native `atlas` command for the local workflow, alongside MCP session briefs, registered worktree aliases, and labelled queries across worktree maps.
- Bounded entry-point and related-code analysis extends the existing caller, dependency, impact, cycle, path, and dead-code candidate views.
- Coordinated runtime/plugin installation, generated host configurations, and packaged Codex session and subagent guidance with readiness checks.
- Unicode-aware case-insensitive literal and fuzzy search, conservative text candidate selection, and reuse of the existing prepared-statement cache for repeated text reads.
- Preserved project identity, worktree isolation, authored purposes, and atomic index publication through supported refreshes and upgrades.
- Map responses on stdout without the legacy generated TOON snapshot file.
- Safer parser-profile cleanup and retry, with indexing deadlines described as cooperative work budgets across setup, traversal, hashing, parsing, and publication.

The [README](../README.md) introduces the complete product, including established capabilities from earlier versions. The detailed [RC4 notes](v0.5.0-rc4-release-notes.md) describe the final candidate corrections. GitHub's generated release history includes the accepted changes since 0.4.5.

## Install or upgrade

Point the coding agent at this repository and ask it to install ProjectAtlas, preferably through the marketplace plugin. For Codex:

```bash
codex plugin marketplace add styler-ai/ProjectAtlas --ref v0.5.0
codex plugin add projectatlas --marketplace projectatlas
```

Follow the version-matched install instructions, then restart the terminal and coding environment. Keep the existing `.projectatlas` directory. The supported installer and typed recovery guidance own runtime, schema, plugin, and host convergence; do not reset the database to resolve a mismatch.

[Installation and recovery](agent-integration.md#runtime-installation-and-repair)

## Platforms and languages

Native packages cover Windows x64, Linux x64, macOS Intel, and macOS Apple Silicon. The optional pack has 150 accepted grammars on Linux x64 and Windows x64; parsing, symbols, and semantic resolution have separate coverage. See the generated [language matrix](language-support.md) and [relation matrix](relation-support.md).

## Release checks

Stable publication uses the existing Rust, documentation, security, OpenSpec, IssueOps, parser-pack, native packaging, installed CLI/MCP/host, and preserved-state upgrade gates. It also requires failure/refusal/retry, cancellation, concurrency, compatible rollback, checksum verification, and independent tag, artifact, installed-runtime, and GitHub Latest readback.

The remaining low-severity KaTeX advisory and parser-only reachability disposition remain documented in [the dependency-policy issue](https://github.com/styler-ai/ProjectAtlas/issues/499). The dependency audit threshold is unchanged.

# ProjectAtlas v0.5.0-rc4 release notes

ProjectAtlas v0.5.0-rc4 is the final planned candidate for v0.5.0. Its release history is cumulative from v0.4.5; stable promotion remains separate work in #602, and v0.4.5 remains GitHub Latest.

## Highlights since v0.4.5

- Add built-in PHP 8 navigation and bounded PDF/DOCX text extraction with exact source evidence, provenance and incomplete-coverage reporting.
- Preserve native project identity, isolated worktree databases, authored purposes and atomic graph publication through refresh and supported upgrades.
- Provide bounded request-owned entrypoint and community analysis through the existing navigation surfaces.
- Converge the installed runtime, versioned plugin, generated host configuration and collision-safe `atlas` command; verify real host readers and packaged hook readiness.
- Return map responses without writing the legacy generated TOON snapshot while preserving the `atlas_map` compatibility route.
- Correct Unicode case-insensitive literal and fuzzy search and conservative persisted-text candidate selection. Repeated text hydration reuses the existing connection-owned prepared-statement cache.
- Bound temporary parser-profile cleanup to one attempt and classify cleanup deadlines as operational failures while preserving containment, reaping and safe retry.
- Describe indexing timeouts as cooperative shared work budgets, including setup after work-control creation, traversal, hashing, parsing and publication checkpoints. Preserve the 30-minute default/ceiling, clamping and fail-closed behavior.
- Include compatible dependency security corrections. The remaining low-severity KaTeX advisory and parser-only reachability disposition remain explicit in [#499](https://github.com/styler-ai/ProjectAtlas/issues/499); the audit gate is unchanged.

## Verification

Publication requires exact-candidate Rust, OpenSpec, IssueOps, package, parser-pack and installed-product proof on Windows, Linux, macOS x64 and macOS arm64. Supported upgrade acceptance starts with the prior stable installation and database and covers authored-state preservation, native runtime/plugin/MCP/host convergence, injected failure, atomic refusal, repair/retry, cancellation, concurrency and compatible rollback or typed prior-runtime refusal.

The release is a non-draft GitHub prerelease with Latest excluded. Candidate preparation alone does not establish that these release checks have passed. GitHub release notes are generated from the accepted pull requests using v0.4.5 as the preceding stable baseline.

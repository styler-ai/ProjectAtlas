# ProjectAtlas v0.5.0-rc3 release notes

ProjectAtlas v0.5.0-rc3 brings the accepted RC2 follow-up fixes and dependency updates into one release candidate. Stable promotion remains separate work in #602; v0.4.5 remains the stable GitHub Latest release.

## Highlights

- Converge the installed runtime, Codex plugin, and MCP registration during marketplace updates.
- Keep repository publication available when DOCX symbols or bounded PDF parsing encounter unsupported content or resource limits.
- Return map responses without creating the legacy generated TOON snapshot, while preserving the `atlas_map` compatibility route.
- Stabilize Windows forwarder migration end-to-end coverage under suite load.
- Restore packaged ProjectAtlas guidance for subagent startup and supported recovery, with a manual fallback when hooks are unavailable. This does not guarantee automatic skill rereading after every subagent compaction.
- Reconcile the accepted dependency updates and select the explicit PR owner before upstream changelog references in protected IssueOps checks.

## Verification

Publication requires exact-candidate Rust, OpenSpec, IssueOps, package, parser-pack, and installed-product proof on Windows, Linux, macOS x64, and macOS arm64. Upgrade acceptance includes the prior stable runtime and database, authored-state preservation, real Codex plugin and MCP convergence, failure refusal, repair/retry, and compatible backup or typed prior-runtime refusal.

The release is published as a non-draft GitHub prerelease with Latest excluded. Candidate preparation alone does not establish that these release checks have passed.

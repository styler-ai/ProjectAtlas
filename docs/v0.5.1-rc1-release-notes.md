# ProjectAtlas v0.5.1-rc1

[RC1 is published](https://github.com/styler-ai/ProjectAtlas/releases/tag/v0.5.1-rc1) as a non-draft prerelease at `327f8565f4007d211771213d6355258c37f028dc`. Its four native packages, installed-product checks, published downloads and checksums passed independent acceptance. **v0.5.0 remains the stable installation default and GitHub Latest.** Stable promotion requires a separate release decision.

## Included work

- Faster initial indexing, full reindexing and one-shot refresh reuse source evidence while preserving exact source and graph reconciliation.
- Corrected cross-language import and caller bindings, bounded relation navigation, document-target admission and external Git exclusion handling.
- Preserved project identity, approved purposes, supported external configuration/storage and native platform behavior through refresh, upgrade, failure and recovery.
- Matched CLI, MCP, plugin and hook delivery, with agent guidance explaining command purpose, when to use each operation, context recovery after compaction and bounded source/specification reflection.

The exact RC1 package benchmark records Windows one-file `atlas watch --once` improving from 12.0878662 to 0.2978412 seconds: **40.58× as fast, about 3958% faster**. This is the measured 1,024-Rust-file fixture with one exported-function change, three paired samples and cold processes with warm filesystem caches; it is not a universal command or full-scan multiplier. The [benchmark record](benchmarks/v0.5.1-indexing.md) retains results for each operation, work counts, resource limits and the separate historical development campaigns.

The four-platform RC1 campaign retains **1,456 of 1,457 passing original checks** and its original failed workflow conclusion. Only the specific retained Windows warm MCP refresh result is accepted as an RC1 tradeoff: 55.3811 ms against the original 55.27709 ms ceiling (10.207% overhead instead of 10%). This does not relax any other report, platform, resource target or release gate. The [campaign record](benchmarks/v0.5.1-rc1-indexing-campaign.json) preserves the exact report and measured executable identities; final publication retains those exact executable bytes and complete package contents.

## Compatibility and packaging

The native matrix covers Linux x64, Windows x64, macOS Intel and Apple Silicon. The optional parser pack covers Linux x64 and Windows x64; macOS uses built-in capabilities. Candidate runtime/plugin versions are `0.5.1-rc1`; accepted capability-set version 20 preserves historical language membership and strength while binding ProjectAtlas-owned provenance to this candidate. The parser consumer manifest and checksums must match the same version.

Existing state is preserved through the supported upgrade paths. Keep compatible backups and follow typed root/schema recovery; do not reset a database to perform an upgrade. The clean parser handoff, isolated native installations, complete CLI/MCP/host behavior, native filesystem and failure/recovery checks passed. All eight uploaded assets and `SHA256SUMS` were independently checked; the [release acceptance record](benchmarks/v0.5.1-rc1-release-acceptance.json) preserves the exact workflow, executable and asset identities.

The release owner is [#715](https://github.com/styler-ai/ProjectAtlas/issues/715). Zero-source-work warm admission (#725) and complete specification/source traceability and purpose-integration verification (#751, RC2) remain outside this candidate.

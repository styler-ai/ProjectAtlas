# ProjectAtlas v0.5.1-rc1

RC1 brings the accepted indexing and refresh improvements together for installed-product acceptance. Candidate publication requires final native-package acceptance and preserves v0.5.0 as the stable installation default and GitHub Latest. Stable promotion requires a separate release decision.

## Included work

- Faster initial indexing, full reindexing and one-shot refresh reuse source evidence while preserving exact source and graph reconciliation.
- Corrected cross-language import and caller bindings, bounded relation navigation, document-target admission and external Git exclusion handling.
- Preserved project identity, approved purposes, supported external configuration/storage and native platform behavior through refresh, upgrade, failure and recovery.
- Matched CLI, MCP, plugin and hook delivery, with agent guidance explaining command purpose, when to use each operation, context recovery after compaction and bounded source/specification reflection.

The accepted implementation benchmark records Windows one-file `atlas watch --once` improving from 12.1032642 to 0.2957054 seconds: **40.93× as fast, about 3993% faster** (rounded: 41× / 4000%). This is the measured 1024-Rust-file fixture with one exported-function change, three samples and a cold process with warm filesystem caches; it is not a universal command or full-scan multiplier. The [benchmark record](benchmarks/v0.5.1-indexing.md) retains path-specific results, work counts, resource limits and original evidence. Final RC package identity and installed acceptance remain release gates.

## Compatibility and packaging

The native matrix covers Linux x64, Windows x64, macOS Intel and Apple Silicon. The optional parser pack covers Linux x64 and Windows x64; macOS uses built-in capabilities. Candidate runtime/plugin versions are `0.5.1-rc1`; accepted capability-set version 20 preserves historical language membership and strength while binding ProjectAtlas-owned provenance to this candidate. The parser consumer manifest and checksums must match the same version.

Existing state is preserved through the supported upgrade paths. Keep compatible backups and follow typed root/schema recovery; do not reset a database to perform an upgrade. The existing clean parser construction, isolated native installation, complete CLI/MCP/host behavior, native filesystem and failure/recovery checks must pass before publication. Published archives must match `SHA256SUMS`.

The release owner is [#715](https://github.com/styler-ai/ProjectAtlas/issues/715). Zero-source-work warm admission (#725) and complete specification/source traceability and purpose-integration verification (#751, RC2) remain outside this candidate.
